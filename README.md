Student Management System

Overview

The Student Management System is a Python-based console application that helps manage student records efficiently. It allows users to add, view, search, update, and delete student information through a menu-driven interface.

Features

- Add new student records
- View all student records
- Search students by Student ID
- Update student details
- Delete student records
- User-friendly menu-driven interface

Technologies Used

- Python 3
- Object-Oriented Programming (OOP)
  

How to Run

1. Install Python 3 on your system.
2. Download or clone this repository.
3. Open the project folder.
4. Run the following command:

python main.py

Sample Menu

1. Add Student
2. View Students
3. Search Student
4. Update Student
5. Delete Student
6. Exit

Skills Demonstrated

- Python Programming
- Object-Oriented Programming (OOP)
- CRUD Operations
- Data Management
- Problem Solving
